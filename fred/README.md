# Fred

Eindelijk een man die aan alles denkt. Fred verdeelt de mental load tussen twee partners: zwemles, belastingaangifte, gymkleren en het juffencadeau staan voortaan in één overzicht dat jullie allebei zien.

## Wat Fred kan

- **Inbox**: plak een mail (school, huisarts, sportclub), spreek iets in („het toiletpapier is op!”) of typ het. Fred haalt er taken, deadlines, tijden en afspraken uit (Nederlandse datums als „voor 1 februari”, „volgende week dinsdag”, „morgenavond om 19:30”).
- **Taken**: toewijzen, deadlines, projecten (bijv. „Schoolkamp”), terugkerende taken (kliko elke week), punten per klus.
- **Agenda**: gezinsmomenten, samen of per persoon. Plant iemand padel op de avond van de Avondvierdaagse, dan waarschuwt Fred.
- **Seintjes**: te late taken, naderende deadlines zonder eigenaar, botsingen in de agenda en de trouwdag (twee weken vooraf). Optioneel als browsermelding.
- **Balans**: punten, gedane en *bedachte* taken per partner over de laatste 7 dagen. Fred geeft een oordeel, mild of keihard eerlijk.
- **Competitie**: levels (van Lanterfanter tot Ome Fred), badges zoals Chief Laundry Officer en Kliko-koning(in), Parent of the month en delen met vrienden.

Alle gegevens staan lokaal in de browser. Delen gaat via exporteren/importeren of één gedeeld apparaat.

## Draaien

```bash
cd fred
npm install
npm run dev     # ontwikkelen
npm test        # parser- en logicatests
npm run build   # productiebuild in dist/
```
